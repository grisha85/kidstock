# AGENT GUIDELINES & CORE PRINCIPLES

## 1. Icon & Emoji Usage Policy (Strict "Grain of Salt")
- **Never over-decorate**: Do NOT prefix every headline, title, card, or label with emojis or decorative icons (e.g., avoid `🧮`, `💵`, `🚀`, `💡`, `✨`, `📖`, `📉📈`, `⚡`, `⚠️`, `🏷️`).
- **Icons strictly for functional utility only**:
  - Interactive navigation controls: Close `X`, expand/collapse chevrons `ChevronDown`/`ChevronUp`, Back buttons.
  - Directional financial indicators: `TrendingUp` / `TrendingDown` where visual direction aids comprehension.
  - Action buttons: primary clear labels without decorative emoji clutter.
  - Educational info triggers: subtle `Info` icon for tooltips.
- **Maintain clean, mature visual hierarchy**: Rely on clean typography, font weights, standard spacing, and subtle border/background accents rather than relying on icons or emojis for styling.

## 2. Target Audience Tone (10y+ Kids)
- Write for 10–14 year olds: Avoid toddler language ("baby talk", animal mascots like lions/elephants for stock sizes).
- Use clear financial and market concepts explained through relatable, real-world analogies (e.g. video game economies, tech products, supply & demand).

## 3. Trading & Modal UX
- Auto-close modals upon successful trade execution (Buy or Sell) to return the user directly to their updated dashboard.
- Always provide clean liquidation options (e.g. "Sell All (100%)") without trapped state loops.
